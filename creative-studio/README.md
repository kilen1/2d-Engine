# Creative Studio - Сайт для дизайнерских услуг и веб-разработки

## Описание проекта

Это полнофункциональный веб-сайт для студии дизайна и веб-разработки, который включает в себя:

- **Портфолио** - галерея выполненных работ с возможностью просмотра проектов
- **Система тарифов** - динамический прайс-лист с возможностью управления администратором
- **Система аккаунтов** - регистрация и авторизация пользователей
- **Чат с администратором** - удобное общение с возможностью прикрепления тарифов к сообщениям
- **Уведомления** - система оповещений для администратора и пользователей

## Возможности

### Для посетителей:
- Просмотр услуг и портфолио
- Просмотр тарифов и цен
- Регистрация и вход в личный кабинет
- Заказ услуг через чат

### Для пользователей:
- Личный кабинет
- Возможность связи с администратором через чат
- Прикрепление тарифов к сообщениям
- Получение уведомлений

### Для администратора:
- Доступ к админ-панели
- Управление тарифами (добавление, удаление)
- Просмотр уведомлений о новых сообщениях
- Общение с пользователями через чат

## Технические особенности

- Полностью адаптивный дизайн
- Современный интерфейс
- Безопасная система аутентификации
- Динамическая загрузка контента
- Интегрированный чат с возможностью прикрепления тарифов

## Как начать работу

1. Откройте файл `index.html` в вашем веб-браузере
2. Для начала работы зарегистрируйтесь как новый пользователь или используйте учетные данные для тестирования
3. Изучите портфолио и тарифы
4. Войдите в аккаунт и попробуйте связаться с администратором через чат
